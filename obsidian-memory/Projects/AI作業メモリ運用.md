# AI作業メモリ運用

## このVaultの目的

Claude Code / Codex などのAIが**セッションをまたいで迷わず再開**できるようにするための長期記憶。  
AIがここを読めば「何が終わっていて、何が残っていて、何を判断したか」がわかる状態を保つ。

---

## フォルダ構成と用途

| フォルダ | 何を置くか |
|---|---|
| `Sessions/` | 作業セッションの記録。`session-YYYY-MM-DD-タイトル.md` で命名 |
| `Projects/` | プロジェクト単位の概要・進捗・方針。このファイルもここ |
| `Decisions/` | 重要な判断・選択の記録。なぜその選択をしたか残す |
| `Failures/` | 失敗・ハマり・回避策。同じ失敗を繰り返さないために |
| `Reference/` | AIへの引き継ぎメモ、よく使うコマンド、設計方針など |

---

## AIへのお願い（セッション開始時のルール）

1. **必ず `Reference/AIへの引き継ぎメモ.md` を読んでから作業を始める**
2. セッション終了時（またはキリの良いタイミング）に `Sessions/session-YYYY-MM-DD-タイトル.md` を作成・更新する
3. 重要な判断をしたときは `Decisions/` に残す
4. ハマった・失敗したときは `Failures/` に残す
5. 次のセッションで続きが必要な場合は `Reference/AIへの引き継ぎメモ.md` の「次回やること」を更新する

---

## セッションノートのテンプレート

```markdown
# セッションログ: [タイトル]

**日付:** YYYY-MM-DD  
**目的:**  
**ステータス:** 進行中 / 完了 / 中断

---

## やったこと

## 決定したこと

## 失敗・ハマったこと

## 次回やること

- [ ] 

## メモ・気づき
```
